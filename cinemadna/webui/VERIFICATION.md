## 二、操作说明（浏览器里怎么走通全流程）

### 启动
```bash
cd E:\CinemaDNA-Claude\cinemadna
python scripts/run_webui.py
```
浏览器打开 **http://127.0.0.1:8700**。

### 验证 1 + 3：建故事 → 一路到成片
1. 「工厂看板」右侧填 **标题** 和 **题材**（如「县城女护士被高利贷追债，最后逆袭翻身」）
2. 渲染后端选 `placeholder`（默认，能出 MP4），模拟场景保持 **无（正常生产）**
3. 点 **创建并开工** → 卡片出现，状态 `CREATED`
4. 反复点卡片上的 **▶ 执行下一步**：
   `SCRIPT_DONE → ASSET_READY → DIRECTING → PERFORMANCE → RENDERING → QA → POST → PUBLISHED → ARCHIVED`
   进度条随之推进，镜头数与时长显示 `8 · 42s`
5. 点卡片 **看成片** → 「成片预览」页播放器直接播 42 秒 MP4，下方时间线 8 行带台词
   - 可下载 **MP4 / 字幕 VTT / EDL**，或打开 **动态分镜**

### 验证 2：人工审核 Gate（通过 / 拒绝）
1. 新建故事时，**模拟场景**选 **「模拟：场景版权风险需人工复核」**
2. 点 **▶ 执行下一步** 到资产阶段 → 状态变 `WAITING_HUMAN`，顶部「人工审核」出现角标
3. 进「人工审核」页 → 看到该故事的待审 Gate（含分数、issues）
4. 填 **审核人** 和 **意见** →
   - 点 **✓ 通过** → 故事回到 `ASSET_READY` 继续流转
   - 点 **✕ 拒绝** → 故事进入 `BLOCKED`
5. 意见会写进故事事件流（在「详情」里可见 `HUMAN_NOTE`），不是只显示在页面

### 验证 4：工单审批
1. 同样用「场景版权风险需人工复核」模拟建一部剧，跑到资产阶段
2. 进「工单」页 → 状态筛选 `GATE_REVIEW` → 待审工单右侧有 **通过 / 拒绝** 按钮
3. 点 **通过**（填意见）→ 该 Gate 裁决生效
4. 把该故事的几个待审 Gate 都放行后 → 故事自动续跑到 `ASSET_READY`
5. 点 **详情** 看工单完整 JSON（含 Gate 报告）

### 验证 5：资产浏览器
1. 进「资产浏览器」页 → 下拉切换 **SceneDNA / IdentityDNA / PropDNA**
2. 表格显示已回流的可复用资产：标签、Master Pack、年龄线、状态版本、过闸、来源剧、hash
3. 这些资产是跨剧共享的——第二部剧用到同类资产会直接复用（工单里显示 `REUSED`）

### 验证红线（附加）
1. 新建故事，模拟场景选 **「模拟：单一真人克隆（红线）」**
2. 跑到资产阶段 → 故事直接 `BLOCKED`
3. 到「工单」页找到该 IDENTITY 工单 → 它的 Gate 带「红线」标记，**没有**通过按钮
4. （即使用 API 强行 POST 通过，也返回 409 HARD_BLOCK）

## 三、关于「模拟场景」

默认流程一路顺利、不会产生待审工单，那样就**没法在浏览器里验证审核链路**。
所以新建故事时可选一个模拟场景，它只往生成参数里注入违规条件，
**不改任何 Gate 判定逻辑**，页面上以 `模拟` 徽章标注：

| 模拟场景 | 触发的路径 |
|----------|------------|
| 无（正常生产） | 全部自动通过，跑到成片 |
| 场景版权风险需人工复核 | 场景 Gate 过但需人工确认 → `WAITING_HUMAN`（验证 2、4） |
| 场景退化为纯 AI 生图 | 违反「自然原子优先」→ Gate 判负 → `BLOCKED` |
| 单一真人克隆（红线） | 硬性拦截 → `BLOCKED`，人工不可推翻 |

> 实现细节：三大库跨剧共享，若上一部剧已回流同类资产，模拟请求会命中复用而
> 跳过生成、参数失效。所以模拟会给场景/角色加唯一前缀强制新生成——
> 这个坑当初漏了，被实测抓出来后已修，并加了回归测试（先填满库再验证模拟仍触发）。
